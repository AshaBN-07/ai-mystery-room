AI Mystery Room

Project Overview

AI Mystery Room is an interactive detective game where players solve fictional mysteries, investigate suspects, discover clues, and identify the culprit.

Features

- Generate mystery stories using AI.
- Choose Easy, Medium, or Hard difficulty.
- Investigate suspects and discover clues.
- Request hints to help solve cases.
- Accuse a suspect and view the result.
- Earn points for correct answers.

Technologies

- HTML, CSS, and JavaScript for learning the frontend.
- React for the interactive interface in a later stage.
- Gemini API for AI-generated mysteries.
- Node.js and Express for the backend when needed.

Security

Never expose API keys in frontend code or commit them to a public GitHub repository. Keep the mystery solution hidden until the player submits an accusation.

Project Goal

Build a mobile-friendly, AI-powered mystery game and publish it as a portfolio project.
